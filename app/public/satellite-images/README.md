# Satellite Images

Place your satellite images in this folder and update `images.json` with their filenames and timestamps.

## Setup

1. Add your satellite image files (e.g., `.jpg`, `.png`) to this folder
2. Edit `images.json` to list each image:

```json
[
  {
    "filename": "your-image-1.jpg",
    "timestamp": "2024-01-01"
  },
  {
    "filename": "your-image-2.jpg",
    "timestamp": "2024-01-02"
  }
]
```

The timestamp can be any format you prefer (date, date-time, etc.).
